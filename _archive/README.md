# _archive — ของเหลือจากเวอร์ชันแรก (ไม่ใช้แล้ว)

ไฟล์ในโฟลเดอร์นี้ **ไม่ได้เป็นส่วนหนึ่งของระบบที่ใช้งานจริง** เก็บไว้เพื่อการอ้างอิงย้อนหลังเท่านั้น
ไม่มีไฟล์ใดในระบบปัจจุบัน `import` หรือเรียกใช้ไฟล์เหล่านี้ (ตรวจสอบแล้ว)

**อย่ารันไฟล์ในโฟลเดอร์นี้** — โค้ดถูกแก้ค้างไว้ครึ่งทางตอนเปลี่ยนสถาปัตยกรรม และจะ error

## โค้ดเวอร์ชันแรก

| ไฟล์ | เคยทำอะไร | ทำไมเลิกใช้ |
|---|---|---|
| `แยกเฟรม.py` | แตกวิดีโอเป็นไฟล์ JPG ทีละเฟรม | เปลี่ยนมาอ่านวิดีโอตรง ๆ ใน `01_extract_landmarks.py` เร็วกว่าและไม่เสียคุณภาพจากการ encode JPG ซ้ำ |
| `สกัดจุด.py` | สกัด landmark จากไฟล์ JPG | รวมเข้าเป็นส่วนหนึ่งของ `01_extract_landmarks.py` |
| `main.py` | เทรนโมเดลเวอร์ชันแรก | มีบั๊กร้ายแรง: แบ่ง train/test **แบบสุ่มรายเฟรม** ทำให้เฟรมข้างเคียงกันตกไปอยู่คนละฝั่ง เกิด data leakage และได้ค่าความแม่นยำสูงปลอม แทนที่ด้วย `03_train_model.py` ที่แบ่งตาม subject |

## ไฟล์ข้อมูลที่เลิกใช้

| ไฟล์ | ทำไมเลิกใช้ |
|---|---|
| `landmarks_train.csv` | สกัดที่ 10 fps แต่เก็บทั้งซ้ายและขวา และไม่มีคอลัมน์ที่ pipeline ปัจจุบันต้องใช้ — แทนที่ด้วย `landmarks_raw.csv` |
| `JPG Student640x480_landmarks.csv` | ผลลัพธ์กลางจาก pipeline เก่าที่สกัดจากไฟล์ JPG |
| `JPG Student640x480_landmarks_labeled.csv` | เวอร์ชันที่ใส่ label แล้วของไฟล์ข้างบน — ปัจจุบันใช้ `CSV Student.csv` เป็นเฉลยหลักแทน |
| `hand_landmarker.task` | โมเดลตรวจจับ **มือ** จากตอนที่ยังไม่ได้ตัดสินใจว่าจะวิเคราะห์อะไร ระบบปัจจุบันใช้ `pose_landmarker.task` (ตรวจจับท่าทางร่างกาย) เท่านั้น |
| `CSV Prototype (โฟลเดอร์ซ้ำ ไม่ได้ใช้)/` | โฟลเดอร์ที่มีไฟล์ `CSV Prototype.csv` ซ้ำกับตัวที่อยู่ใน `data/` ไม่มีสคริปต์ใดอ้างถึงโฟลเดอร์นี้ ไฟล์ตัวจริงที่ใช้งานอยู่ที่ `data/CSV Prototype.csv` |
